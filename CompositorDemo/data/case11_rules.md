# 案例 11：自避式分形面叠 (case11_self_avoiding_sheets)

## 1. 物理模型与数学规则

### 1) 拓扑重写规则
$$\{\{x, y, z\}\}|_{s(x)=+1} \longrightarrow \{\{x, u, v\}, \{u, y, w\}, \{v, w, z\}, \{u, v\}, \{v, w\}, \{w, u\}\}$$

高阶3元等边大分裂。通过对细分边缘的方向逆转定义，使得在向外极速扩张分裂时，空间发生自我避让（Self-Avoiding）物理现象。

### 2) 单元状态自组织更新
- **状态计算策略**：**OscillationWave (模三循环衰减波动)**
- **激发变迁机制**：流动电势顺着高度曲褶的扇形面边缘波浪推进，形成宏大的同心相干流动电场。

## 2. 模拟运行实测分析

- **终止演变步骤**：第 05 步
- **活跃节点总数 (N)**：1026
- **活跃超边总数 (E)**：1024
- **状态值终态统计**：$+1: 849$，   $-1: 99$，   $0: 78$
- **模拟总演化耗时**：848.417µs

### 3D 渲染与空间计算 (visionOS VR) 展现特征

拓扑不向大铁球坍缩。反而在 3D layout 中舒展拉平成如风折叠的蕾丝群花片，每一片薄膜都有深度纵深层级，十分具有空间雕塑美学。

在 visionOS 等头戴 MR 空间计算平台中，程序可以通过裸指针形式直接加载本案例的 `*_final.bin` 极速二进制资产，以微秒级耗时瞬间解构出由力学引力（Fruchterman-Reingold）收缩及斥力扩散后均衡分布的 `[x, y, z]` 坐标，并通过实例化 ModelEntity 将三元关系描绘为半透明三角形发光层叠群，具有极其优异的立体空间展现度与交互趣味。
