# 案例 2：三维有向珊瑚格网 (case2_wave_resonance)

## 1. 物理模型与数学规则

### 1) 拓扑重写规则
$$\{\{x, y\}\}|_{s(x)=+1} \longrightarrow \{\{x, u\}, \{u, v\}, \{v, y\}, \{u, w\}, \{w, v\}\}$$

通过匹配有向正电连边并将其替换为带有并行分叉环的多级珊瑚管。节点的最大度数完全受限，结构分布均匀，呼吸感极好。

### 2) 单元状态自组织更新
- **状态计算策略**：**OscillationWave (模三循环衰减波动)**
- **激发变迁机制**：状态粒子顺着状态敏感的珊瑚分枝网络进行电荷偏好对流传输。

## 2. 模拟运行实测分析

- **终止演变步骤**：第 06 步
- **活跃节点总数 (N)**：1136
- **活跃超边总数 (E)**：1513
- **状态值终态统计**：$+1: 403$，   $-1: 459$，   $0: 274$
- **模拟总演化耗时**：2.292334ms

### 3D 渲染与空间计算 (visionOS VR) 展现特征

立体珊瑚格网在引力斥力下，节点各向舒张，平均度数保持在2.5至3.1的黄金舒适范围，整体外观十分透气灵动，仿佛海洋深处静静闪烁呼吸的发光有机软网巢。

在 visionOS 等头戴 MR 空间计算平台中，程序可以通过裸指针形式直接加载本案例的 `*_final.bin` 极速二进制资产，以微秒级耗时瞬间解构出由力学引力（Fruchterman-Reingold）收缩及斥力扩散后均衡分布的 `[x, y, z]` 坐标，并通过实例化 ModelEntity 将三元关系描绘为半透明三角形发光层叠群，具有极其优异的立体空间展现度与交互趣味。
