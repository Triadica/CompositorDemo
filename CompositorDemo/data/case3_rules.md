# 案例 3：激发孤子分形隧道传输 (case3_soliton_tunneling)

## 1. 物理模型与数学规则

### 1) 拓扑重写规则
$$\{\{x, y, z\}\}|_{s(x)=+1} \longrightarrow Sierpinski(3-arity) + \{\{u, v\}, \{v, w\}, \{w, u\}\}$$

标准的等分三角面匹配。通过在新产生的突刺节点间添加起稳定拓扑和提升维度的二元辅助连边，巧妙地将平均度数推升至 2.8 以上。

### 2) 单元状态自组织更新
- **状态计算策略**：**ExcitableSoliton (激发-暂态冷熄孤子)**
- **激发变迁机制**：孤子电磁波在带有附加二元辅助连结的自相似非欧三角网中运行亮灭传递。

## 2. 模拟运行实测分析

- **终止演变步骤**：第 05 步
- **活跃节点总数 (N)**：1026
- **活跃超边总数 (E)**：1024
- **状态值终态统计**：$+1: 770$，   $-1: 0$，   $0: 256$
- **模拟总演化耗时**：888.666µs

### 3D 渲染与空间计算 (visionOS VR) 展现特征

在3D视图中完美展开呈一个自中心旋转辐射的分形三角中空套环结构。孤子的非线性亮灭信号顺着网格边缘优雅穿行，没有任何死角与节点粘连，充满科幻质感。

在 visionOS 等头戴 MR 空间计算平台中，程序可以通过裸指针形式直接加载本案例的 `*_final.bin` 极速二进制资产，以微秒级耗时瞬间解构出由力学引力（Fruchterman-Reingold）收缩及斥力扩散后均衡分布的 `[x, y, z]` 坐标，并通过实例化 ModelEntity 将三元关系描绘为半透明三角形发光层叠群，具有极其优异的立体空间展现度与交互趣味。
